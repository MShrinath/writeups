HackHavoc is a Capture The Flag (CTF) competition hosted by CyberMaterial. The event features a diverse range of challenges across core cybersecurity domains, including Cryptography, OSINT (Open Source Intelligence), Web Exploitation, and Reverse Engineering. Designed for both beginners and experienced participants, HackHavoc provides a hands-on environment to sharpen practical skills and tackle real-world security scenarios.
